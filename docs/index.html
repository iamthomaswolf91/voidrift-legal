VOIDRIFT

Customize. Upgrade. Survive.

VOIDRIFT is a browser-based vertical-scrolling space shooter. Pick a ship class, equip weapons, fight through sectors and boss battles, and team up with a friend in online two-player co-op. It can be played in a web browser and as a Discord Activity inside a voice channel.
