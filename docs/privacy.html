2. What the Game processes

  • On your device (local storage): pilot name, ship loadouts, upgrades, currency, cosmetics and settings. This stays in your browser and is not sent to us except as described below.
  • Online co-op: when you create or join a co-op room, your pilot name, ship loadout and game inputs are sent to the game server so the match can run. Room data is held in server memory only while the room exists and is discarded afterwards. It is not stored in a database.
  • Technical data: like any web server, the hosting infrastructure necessarily sees your IP address and basic request data to deliver the Game. [CONFIRM: hosting provider, location, and whether it keeps access logs]

3. Discord Activity

If you play inside Discord, the Game asks Discord for permission to read your basic profile (the identify scope). We use your Discord display name only as your default pilot name, and the Activity instance ID to put people from the same voice channel into the same room. Your authorization code is exchanged for an access token by our server; the token is used to confirm your identity in the Activity and is not stored by the Game. Discord processes your data under its own privacy policy.

4. What we do not do

The Game currently has no user accounts, no advertising, no analytics or tracking cookies, and no payment processing, and does not sell your data. There is no chat feature. [CONFIRM: still accurate at publication]
